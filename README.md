# Student Performance Tracker

A console-based Python application to manage student records, marks and attendance. Data is saved in a JSON file.

## Features
- Add students with marks in 3 subjects and attendance
- Automatic average and grade (A / B / C / Fail)
- View all students and individual report cards
- Low attendance warning (below 75%)
- Update marks, show topper, delete student
- Input validation (no crash on wrong input)

## Technologies
- Python 3
- JSON file handling

## How to Run
```
python student.py
```

## Concepts Used
Dictionaries, functions, exception handling (try/except), `max()` with key, file handling.
